# coveira-site

Crie um site interativo completo usando apenas HTML, CSS e JavaScript puro (sem frameworks), pronto para hospedar no GitHub Pages.

OBJETIVO:
O site deve ter um tema de cemitério gótico, misterioso e imersivo, com uma sepultura interativa centralizada. O design deve ser bonito, responsivo, animado e com atmosfera sombria e elegante.

ESTRUTURA VISUAL:

- O fundo deve ser um cemitério noturno decorativo, com:
  - Céu escuro com lua e estrelas
  - Névoa animada suave
  - Silhuetas de árvores mortas
  - Ambiente misterioso estilo gótico, porém limpo e elegante

- No centro exato da tela deve existir uma sepultura com o texto:

  Coveira

- A sepultura deve parecer realista (pedra, textura, sombra, profundidade).
- Deve haver um leve efeito de brilho, névoa ou partículas ao redor.

INTERAÇÃO:

- A sepultura deve ser clicável.
- Quando o usuário clicar nela:

  1. A câmera deve dar um leve zoom suave.
  2. Uma animação deve iniciar mostrando uma pá cavando a terra.
  3. A terra deve se abrir gradualmente.
  4. Um caixão deve surgir de dentro da cova.
  5. O caixão deve abrir lentamente com animação suave.

- Dentro do caixão, deve aparecer o seguinte texto, com efeito de fade-in ou efeito de escrita animada:

"Estou enviando essa carta, direto dos monges de ratanaba, com ajuda do Deus tupã e paje rasmisin, eu te envio esse recado, para mulher mais linda de itapevi, condessa de Bucha city, rainha dos macacos, senhora das torres, empadao de pirituba, carcajo dos ceus estrelados da linda noite do katongo. Os deuses Tupi, me falaram em sonhos, grandes revelaçoes BOMBASTICAS e que eu deveria revelar todos esses segredos a voce. Dito isso, gostaria de marcar encontro com voce, pelo bem da humanidade, voce aceitaria ter encontro comigo oh Deusa ruiva, rainha dos macacos?"

ESTILO E ANIMAÇÕES:

- Use CSS animations e transitions suaves
- Use efeitos como:
  - Fade-in
  - Zoom
  - Glow suave
  - Névoa animada
  - Tremor leve ao abrir a cova

- Tipografia estilo gótico ou medieval

- Cores principais:
  - Preto
  - Cinza escuro
  - Azul noturno
  - Roxo escuro
  - Branco suave para texto

REQUISITOS TÉCNICOS:

- Código organizado em:
  - index.html
  - style.css
  - script.js

- Não usar frameworks
- Não usar bibliotecas externas
- Deve funcionar abrindo apenas o index.html

EXTRAS OPCIONAIS (se possível):

- Som leve ao clicar na sepultura
- Efeito de névoa animada com CSS
- Efeito de partículas

RESULTADO FINAL:

Um site interativo, imersivo e impressionante, com animações suaves, visual gótico e experiência envolvente, ideal para enviar como surpresa.

Forneça o código completo dos três arquivos.
